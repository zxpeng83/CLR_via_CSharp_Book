# 《CLR via C#》学习补充笔记

本套笔记已完成30章整理、逐章独立验收及全局验收。

本套笔记整理原有元宝问答，按《CLR via C#》第4版的章节组织。正文围绕关键疑问展开，保留有实质差异的知识、代码、类比与例子，纠正错误，并在相关位置说明现代 C#/.NET 的变化。没有实质讨论的章节只说明来源范围与关联内容，不扩写整章教材。

## 阅读方式

- 从下面的章节目录进入正文；每章用主题目录定位具体疑问和例子。
- 默认在原书时代的语境中理解规则；现代变化在相关位置另作说明。
- 代码前的标记区分完整程序、局部片段、反例、伪代码和IL，不能把全部代码块拼成一个程序。
- 章末重要纠错对照说明原误解、正确结论及依据；来源与详细核验集中存放在辅助记录中。
