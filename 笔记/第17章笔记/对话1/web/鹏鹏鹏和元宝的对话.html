1. qsort 是什么？

qsort 定义在 C 标准库 <stdlib.h> 中，原型大致是：
c
void qsort(
    void *base,           // 要排序的数组起始地址
    size_t nmemb,         // 元素个数
    size_t size,          // 每个元素的大小（字节）
    int (*compar)(const void *, const void *)  // 比较函数指针
);
关键点：
qsort 只负责“怎么排”（算法），但完全不知道你怎么比较两个元素，所以它要求你传一个 函数指针（compar），这个函数由你来写。

2. 为什么 qsort 一定要回调？

因为 qsort 是通用排序算法：
  • ••
    它不知道你排的是 int[]、double[]、结构体数组，还是字符串数组
  • ••
    它也不知道你是要升序还是降序
  • ••
    甚至不知道你的排序规则（按年龄？按姓名？）
所以它把“比较两个元素大小”这件事交还给你，这就是回调（callback）。

示例（C 语言） 

c
#include <stdlib.h>
#include <stdio.h>

int compare_ints(const void *a, const void *b) {
    int ia = *(int *)a;
    int ib = *(int *)b;
    return ia - ib;  // 升序
}

int main() {
    int arr[] = {4, 2, 9, 1};
    qsort(arr, 4, sizeof(int), compare_ints);
}
这里发生了什么？
  1. 1.1.
    qsort 内部会多次调用 compare_ints
  2. 2.2.
    qsort 反过来调用你提供的函数
  3. 3.3.
    这就是“回调”

三、Counter：委托的“使用者” 

csharp

    for (Int32 val = from; val <= to; val++) {

  • ••
    fb(val) 实际调用的是：fb.Invoke(val)
  • ••

    • ••
      是静态还是实例
    • ••
      是打印、弹框还是写文件
  • ••

六、ChainDelegateDemo1：委托链（多播委托）

构建委托链 

csharp
Feedback fbChain = null;
fbChain = (Feedback)Delegate.Combine(fbChain, fb1);
fbChain = (Feedback)Delegate.Combine(fbChain, fb2);
fbChain = (Feedback)Delegate.Combine(fbChain, fb3);

发生了什么？

  • ••
    Delegate.Combine 不会修改原有委托
  • ••
    而是创建一个新委托
  • ••
    _invocationList 变成一个数组：
纯文本
[ FeedbackToConsole,
  FeedbackToMsgBox,
  FeedbackToFile ]

调用时： 

csharp

等价于：
csharp
FeedbackToConsole(1);
FeedbackToMsgBox(1);
FeedbackToFile(1);
⚠️ 注意：一旦某一个抛异常，后面的都不会执行

csharp
Delegate.Remove(fbChain, new Feedback(FeedbackToMsgBox));
  • ••
    不是“移除同一个对象引用”
  • ••
    而是按方法签名匹配
  • ••
    返回一个新的委托链

七、ChainDelegateDemo2：+= / -= 语法糖（⭐重点） 

csharp

编译器实际做的事： 

csharp
fbChain = (Feedback)Delegate.Combine(fbChain, fb1);

✅ += / -= 只是语法糖
✅ 背后仍然是 Combine / Remove
✅ 委托是不可变对象

八、为什么需要 new Feedback(...)？

你可能会问：
为什么 Remove 的时候还要 new Feedback(...)？
因为：
  • ••
    委托比较的是 _target + _methodPtr
  • ••

  • ••
    new Feedback(FeedbackToMsgBox) 会生成一个指向同一方法的委托
这在 CLR 层面是等值匹配，不是引用匹配。

四、情况 2：想给参数设默认值

❌ Action 不支持默认值 

csharp

csharp

原因很简单：
默认值写在“方法定义”上，不是写在“委托签名”上。

✅ 正确做法：默认值写在方法上 

csharp

class Program {
    static void Foo(int x = 10) {
        Console.WriteLine(x);
    }

    static void Main() {
        MyDelegate d = Foo;
        d();      // 输出 10
        d(20);    // 输出 20
    }
}
📌 默认值生效的前提：是你自己定义的 delegate
